# Screenshots

English · [한국어](README.ko.md)

This folder holds two separate sets of captures. To keep them from looking mixed, here
is what each one is.

- **`en/` — the real ARTEX UI, captured in the default English display language.** This is
  what this repository delivers. The main docs [`../README.md`](../README.md) and
  [`../README.ko.md`](../README.ko.md) use these images. If you only want the delivered
  English screens, open the [`en/`](en/) folder.
- **The `*.png` files in the root — UI captures of the upstream original (Chinese edition).**
  They are **preserved as-is** so that they can be compared 1:1 against the upstream
  repository, and the preserved Chinese README [`../README.zh.md`](../README.zh.md)
  references them. The Korean and English docs do not use them.
- **`wx.png` — the upstream author's WeChat official-account promo image.** Kept so that
  [`../README.zh.md`](../README.zh.md) still renders unchanged. It is unrelated to this
  fork.

In short, the Chinese screens you see first in the root are there because the upstream
originals are preserved; the **delivered English screens live in [`en/`](en/).** Why this
repository keeps the originals alongside (localization transparency and comparison against
upstream) follows the same reasoning as its defense-and-detection positioning; see the root
README for the full background.
