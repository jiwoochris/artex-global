# Screenshots

This folder holds two separate sets of captures. To keep them from looking mixed, here is what
each one is.

- **`en/` — real UI of ARTEX in the default English display language.** This is what the fork
  delivers, and what the main document [`../README.md`](../README.md) uses. For the delivered
  screens, open [`en/`](en/).
- **The `*.png` files in the root — upstream (Chinese edition) UI captures.** They are
  **preserved as-is** so the fork can be diffed against the upstream repository 1:1. The
  documentation in this repository does not use them.
- **`wx.png` — the upstream author's WeChat channel promo image.** Kept so the upstream capture
  set stays complete. It is unrelated to this fork.

In short, the Chinese screens in the root are there for upstream preservation; the **delivered
screens live in [`en/`](en/).** See the root README for why this fork keeps the originals alongside
(localization transparency and upstream comparison).
